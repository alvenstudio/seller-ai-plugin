# Товарная этикетка

Рендер — локально (`scripts/`, reportlab + python-barcode, шрифт Inter в `fonts/`). Данные карточки — инструментом MCP
Seller AI `products_get`; реквизиты продавца и всё, чего в Seller AI нет, — из `labels-config.json` в рабочей папке
пользователя (в git не попадает). Образец — `references/labels-config.example.json`.

## Откуда что берётся

| Поле | Источник |
|---|---|
| название, SKU, артикул, штрихкоды | `products_get` → `item.name`, `item.sku`, `item.offer_id`, `item.barcodes` |
| масса нетто | из названия карточки («… 400 г»); вес из `details.dimensions` — брутто упаковки, на этикетку не идёт |
| упаковщик / производитель, ИНН, КПП, адрес, телефон | `labels-config.json`: `legal_entities` и `stores.<store_id>.owner` |
| состав, КБЖУ, срок годности, условия хранения, страна | `labels-config.json` → `products.<store_id>.<sku>`, или со слов пользователя флагами |
| дата упаковки, срок, другие значения из чата | флаги `make_label.py` — поверх всего |

Характеристик карточки (состав, КБЖУ, срок, хранение, страна, масса нетто) Seller AI пока не отдаёт: спросить у
пользователя один раз и сохранить в настройки товара (`label_config.py set`) после его «да». Не выдумывать: чего нет —
назвать «проверить перед печатью».

## Порядок

1. **Товар.** `stores_list` → `store_id`. `products_list` с `search` по словам пользователя (в названии, артикуле, SKU,
   штрихкоде); несколько кандидатов — показать и спросить. Одно название в двух фасовках — взять ту, чей вес назван
   (вес в `name`, а не только в артикуле), двойника назвать. Расхождение веса в артикуле и в названии — ошибка карточки,
   назвать. Карточки нет — предложить: разовую этикетку со слов пользователя, товар в другом магазине или завести карточку
   (в кабинете Ozon).
2. **Карточка.** `products_get` (`product` = `product_id`) — сохранить ответ в файл `product.json`.
3. **Тип надписи и юрлицо** (если в настройках товара их нет — спросить): только штрихкод (`barcode_only`) или с
   реквизитами; «Упаковано» (`packer`), «Производитель» (`manufacturer`), «Изготовитель» (`maker`); юрлицо — владелец
   магазина (по умолчанию) или другое (`--packer <фамилия>` ищет в `legal_entities`; нет там — `--packer-name` и реквизиты
   флагами, пустые назвать). Реквизиты нового юрлица — `label_config.py set-entity … [--owner-of <store_id>]`.
4. **Даты.** Сверять с сегодняшней датой по Москве. Названный «срок» уже в прошлом — почти наверняка это дата упаковки:
   уточнить одним вопросом, не печатать просроченную этикетку.
5. **Рендер:**

```bash
python3 scripts/make_label.py --product product.json --store <store_id> \
    --title "КУРАГА БЕЗ САХАРА" --packing-date 01.10.2026 [--config labels-config.json]
```

| Флаг | Когда |
|---|---|
| `--title "…"` / `--no-title` | короткий заголовок КАПСОМ (по умолчанию — из настроек; для `barcode_only` добавлять вес: «ФИНИКИ МАЗАФАТИ, 500 Г») / «убери заголовок» |
| `--label-type packer\|manufacturer\|maker\|barcode_only` | тип надписи |
| `--packer "<фамилия>"`, `--packer-name "ИП …"` + `--inn/--kpp/--address/--phone` | упаковщик не владелец магазина |
| `--packing-date`, `--shelf-life`, `--storage`, `--composition`, `--country`, `--weight`, `--barcode` | значения из чата — поверх карточки и настроек |
| `--no-barcode`, `--hide-country`, `--size 58x60`, `--out`, `--json`, `--no-png` | по необходимости |

6. **Проверка.** Скрипт рядом с PDF кладёт PNG (`pdftoppm`): посмотреть глазами, что текст не обрезан. Строки «⚠️ …»
   назвать пользователю: какой штрихкод взят из нескольких, какой код выброшен и почему, чего не хватает, пустые реквизиты.
7. Отдать PDF; имя — понятное человеку: «Этикетка <товар> <вес> <магазин> <дата>.pdf». Спросить, сохранить ли настройки
   товара (заголовок, тип, упаковщик, штрихкод, состав) — `label_config.py set --store … --sku … …`.

## Штрихкод

- Берётся первый годный EAN-13 карточки (`item.barcodes` в порядке Ozon) или из настроек/флага. Годный — 13 цифр с верной
  контрольной цифрой или 12 цифр (EAN-13 без контрольной — она дописывается). Коды `OZN…`, 9-значные, с неверной
  контрольной цифрой на этикетку не выводятся — скрипт предупреждает, назвать это пользователю.
- Несколько кодов — назвать выбранный. «ШК возьми из магазина X» — найти карточку X по названию и весу и взять её EAN-13;
  у каждого веса свой код.
- В карточке EAN-13 нет: новый код можно сделать локально (`python3 scripts/ean13.py new` — префикс 200), но привязать его к
  карточке через Seller AI **пока нельзя**: сказать, что код к карточке не привязан и его нужно добавить в кабинете Ozon,
  иначе склад не опознает товар. Проверить код — `python3 scripts/ean13.py check <код>`.

## Тонкости вёрстки

- По умолчанию — только шаблон `generate_label_pdf` (заголовок сверху, сплошной текст, ШК горизонтально внизу, дата
  упаковки отдельной строкой; шрифт подбирается по месту). Присланный образец задаёт **формулировки** (тип надписи, формат
  массы «0,45 кг ± 0,02 кг», состав и реквизиты дословно), а не вёрстку; даты — из последней фразы пользователя.
- Урезанные этикетки: без ШК — `--no-barcode`; без состава/КБЖУ/срока — пустые поля;
  без даты/страны — `show_packing_date: false` / `--hide-country`. «Жирность меньше» — `font_bold: false` в данных.
- Своя вёрстка («всё на одном уровне», вертикальный ШК) — только по прямой просьбе: reportlab-канвасом с
  `generate_label.register_fonts()`.
- Правка присланного PDF («такую же, но с датой X»): не перегенерировать, а наложить новый текст — `pdftotext -bbox`
  даёт координаты слова, `pdffonts` — шрифт; белый прямоугольник по bbox и новый текст тем же шрифтом (pypdf `merge_page`),
  проверить рендером.
- Без карточки состав/КБЖУ «из интернета» — только по прямой просьбе и с пометкой «сверить с упаковкой поставщика».
- Противоречия карточки (страна против состава, холодильник для сухофруктов, вес в артикуле против названия) молча на
  этикетку не переносить — назвать и предложить поправить карточку. Прислали декларацию — сверить с ней реквизиты.

## Данные для `generate_label_pdf` (ручная сборка, разовая этикетка)

`title`, `name`, `label_type`, `kbzhu` `{protein, fat, carbs, calories}`, `shelf_life`, `storage_conditions`,
`legal_entity`, `inn`, `kpp`, `address`, `phone`, `country`, `weight`, `packing_date`, `barcode`, `show_country`,
`show_packing_date`, `font_bold` (`"title_only"` по умолчанию).

```bash
python3 scripts/generate_label.py --data data.json --output label.pdf --width 58 --height 40
```
