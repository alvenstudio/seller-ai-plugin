# Создать или скопировать карточку

Три команды с правом `products.write`, до 100 карточек в `body.items`. Доступ ограничен пилотом: `409 pilot_only`
означает, что создание для выбранного магазина ещё не открыто. Не выбирать другой магазин в обход ограничения.

До сбора полей прочитать `products_capabilities_get` для выбранного магазина. `creation_available: false` — сразу
назвать ограничение из `creation_unavailable_reason`, не собирать анкету и не отправлять создание. Не удалось проверить
доступность — назвать ошибку; неизвестное разрешение не считать разрешением. `true` определяет допуск магазина,
а право `products.write` проверяется отдельно. Доступность обычного редактора и остатков эта проверка не определяет.

## Выбрать действие

| Просьба | Инструмент | Поля элемента |
|---|---|---|
| Новая карточка из своих данных | `products_create` | Полные поля ниже |
| Своя копия в том же магазине | `products_copy` | `{product_id, new_offer_id}` |
| Карточка другого продавца по SKU | `products_create_by_sku` | `{sku, offer_id, price, currency_code, vat, name?, old_price?}` |

`products_create_by_sku` не копирует свою карточку: `own_sku` — выбрать `products_copy`, не пытаться поменять вид SKU.
Своя копия сохраняет читаемые содержимое, медиа, габариты и цены источника. Исходные ID, SKU, штрихкод и характеристику
артикула 9024 Seller AI исключает; источник не меняется. Для переноса между своими магазинами отдельной команды копии нет:
по явно названным источнику и целевому магазину можно собрать `products_create` из своих полей, без исходных идентификаторов
и штрихкода; НДС и цены целевого магазина должны быть заданы пользователем, не угаданы по соседним товарам.
Если чтение источника не позволяет восстановить отдельные экземпляры комплексных характеристик без потерь,
автоматический перенос недоступен: не объединять повторные экземпляры и не выбрасывать их ради отправки.
«Перенеси» может означать создание второй карточки или уход из исходного магазина: уточнить цель, новый артикул,
цены/валюту/НДС и судьбу источника. Создание само по себе не разрешает архивировать или удалять источник.

## Подготовить

1. Найти источник, если нужен: `products_get`, `products_content_get`, `prices_products_get`. Источник не назван — искать
   в доступных магазинах одним `combined_products_list`; недоступные магазины ответа назвать. Две фасовки — уточнить.
2. Проверить похожие товары целевого магазина через `products_list` по словам названия, исключив сам источник копии.
   Неожиданный дубль или странность — назвать, уточнить намерение; явно согласованную копию повторно не подтверждать.
   Новый артикул проверить точно через `products_search` (`field=offer_id`, включая архив);
   окончательную свежую проверку и блокировку делает команда. Артикул — одна строка, до 50 символов, без пробелов по краям.
3. Для `products_create` обязательны `offer_id`, `name`, `description_category_id`, `type_id`, `attributes`,
   `depth`, `width`, `height`, `weight`, `price`, `currency_code`, `vat`. Категорию и тип найти через
   `products_categories_tree` с `search`, заполнить обязательные характеристики из `products_categories_attributes_list`;
   словарные значения — из `products_categories_attribute_values_list`. ID передаются строками.
4. Габариты и вес — положительные целые: по умолчанию `mm` и `g`, также `cm`/`in`, `kg`/`lb`; максимум 1000 кг.
   Цена положительная, до копейки; `old_price` — 0 или выше цены. Ставку НДС и валюту не угадывать.
5. Дополнительно: `barcode`, `primary_image`, `images`, `color_image`, `pdf_list[{name,src_url}]`,
   `complex_attributes[{attributes:[…]}]`. Не переносить 9024, ID товара, SKU и штрихкод источника.
   Название задаёт `name`; описание, Rich и видео — соответствующие характеристики, как в основном навыке.
   Фото только свои или присланные пользователем, включая разрешённые загрузки Seller AI; для видео, Rich и PDF
   нужны постоянные общедоступные ссылки. Без `barcode` команда не обещает заранее сгенерированный код.

## Отправить и проверить

- Полная просьба с выбранным магазином и заполненными полями — согласие на создание. Если чего-то не хватает,
  собрать недостающие сведения одним уточнением. Один `idempotency_key` на это намерение, сохранить его для проверки ответа.
- `offer_id_taken` — новый артикул занят; `creation_preflight_unavailable` — свежую проверку провести нельзя, отправки нет.
  Не менять ключ и не отправлять тот же импорт в обход отказа. `products_stale` у копии — источник нельзя сохранить без
  потерь; назвать `missing`, не отбрасывать поля, чтобы протолкнуть импорт.
- `200`/`202` и номер задачи Ozon — ещё не завершение. Следить через `operations_get`; `outcome_unknown` не пересылать.
  Тот же ключ и тело возвращают прежнюю операцию, другое тело с тем же ключом — `idempotency_conflict`.
- Новый `product_id` брать только из `items[].observed.product_id` подтверждённого элемента. Затем `products_get`:
  создание и модерация различаются, `status` и `issues` показывают готовность продажи. Отказ Ozon привести его словами.
  Пустые остатки и отсутствие SKU сразу после создания не выдавать за поломку; штрихкод печатается только после привязки.

«Скопируй товары с > N заказов за месяц» — сначала `analytics_products_list` за 30 дней по вчера с `sort=ordered_units`,
без «Уценённого товара» и уже существующих в целевом магазине; показать отбор, заказы и пропуски. Неизвестные цену, НДС,
новые артикулы и разрешение использовать содержимое эта формулировка не задаёт.
