# Заказы и отправления (FBO, FBS, realFBS)

Только чтение. Сборка, этикетки, отмена и отгрузки FBS — навык `fbs-orders`. Сколько заказали, продали или отгрузили за
период (штуки, суммы, по дням и товарам) — навык `sales-analytics`.

## Какой инструмент брать

| Вопрос | Инструмент | Главное в аргументах |
|---|---|---|
| Заказы всех схем одним списком с фильтрами | `orders_list` | `date_from` / `date_to` — дни МСК по дате создания; `scheme`, `status` (через запятую), `sku` или `offer_id`, `warehouse_id`; `limit` ≤ 500 |
| Вкладка «FBO → Заказы» | `postings_fbo_list` | `tab`, `period` или даты, `search` (артикул, название, SKU) |
| Вкладка «FBS → Заказы» | `postings_fbs_list` | `tab` (по умолчанию `awaiting_packaging`), `warehouse_ids`, `delivery_method_ids`, `shipment_day` (`today`/`tomorrow`), `search` |
| Одно отправление | `postings_fbo_get` / `postings_fbs_get` | `posting` — номер |
| Что Ozon начислил по отправлению | `finance_accruals_list` | `search=<номер>`, `search_scope=all` |

- Номер заказа в `posting_number` находит все отправления заказа (и разделённого).
- Списки отправлений листать по `next_cursor` до `null`. Без периода `postings_fbo_list` берёт три месяца,
  `postings_fbs_list` — все дни.

## Как читать ответ

- `products[].price` — «Предельная цена»: цена продавца за штуку после его акций, до скидок Ozon; `total` — Σ цена ×
  количество. Цены покупателя и скидки Ozon (СПП) в Seller AI нет — так и сказать, не выводить из других полей.
- Комиссии, зачёркнутой цены и скидок строки в заказах нет: удержанное Ozon — начисления по отправлению (ниже), ставка
  товара — навык `category-commissions`. `payout` в `orders_list` — выплата по строке, как её отдал Ozon (часто `null`);
  факт денег — начисления.
- Время в ответах — UTC, пользователю — по МСК. FBO-список идёт по `created_at`, FBS — по `in_process_at` («Принят»).
- FBS: `shipment_date` — срок отгрузки, `shipment_date_without_delay` — «Дата отгрузки без просрочки», `tariff` — «Тариф
  отгрузки» (навык `fbs-orders`), `needs_additional_info` — нужна маркировка или ГТД, `parent_posting_number` — из какого
  отправления выделено, `scheme: rfbs` — realFBS (доставка не Ozon).
- `postings_fbo_get` / `postings_fbs_get`: `buyer.type` — `legal` (юрлицо) или `individual`; `cancellation` — причина,
  кто отменил (`initiator`), после отгрузки ли, входит ли в рейтинг отмен (`affect_cancellation_rating`). У FBS ещё
  габариты и вес строк, плановая доставка, `tariff_base` — «Сумма для расчёта тарифа». Персональных данных покупателя нет.

## Неполные ответы и ошибки

- Отправление, которого ещё нет в Seller AI, `postings_fbo_get` / `postings_fbs_get` читают из Ozon сами
  (`source: observed_now`) — отдельно просить не нужно.
- Пока синхронизация грузит заказы, списки отвечают первой страницей из Ozon с `warnings` «Отправления ещё загружаются
  из Ozon…»: сказать, что список и счётчики пока неполные. Остальные `warnings` — пересказать.
- `coverage.period_covered = false` — история не покрывает весь период: так и сказать.
- 404 — отправления нет ни в Seller AI, ни в Ozon. 409 `seller_unavailable` — нет рабочего ключа Seller API, повтор не
  поможет.

## Начисления по отправлению

`finance_accruals_list` с `search=<номер>` и `search_scope=all` ищет по всем датам (`unit_number` — номер отправления).
В строке: `amount` (продажа +, удержания −), `type_name`, `children[]` — разбивка («Выручка», «Вознаграждение за
продажу», логистика, обработка, доставка до места выдачи…). У свежего отправления начислений ещё нет — «ещё не
начислено», не 0. За период — `from`/`to` и `scheme` без `search`, сгруппировать по `unit_number`.

## Статусы Ozon

| Статус | FBO | FBS |
|---|---|---|
| `awaiting_registration` | — | ожидает регистрации |
| `acceptance_in_progress` | — | принимается |
| `awaiting_approve` | — | ожидает подтверждения |
| `awaiting_packaging` | ожидает упаковки | ожидает сборки |
| `awaiting_deliver` | ожидает доставки | ожидает отгрузки (собрано) |
| `sent_by_seller`, `driver_pickup` | — | отгружено продавцом / забрал курьер |
| `delivering` | доставляется | доставляется |
| `arbitration`, `client_arbitration`, `not_accepted` | — | спорные |
| `delivered` | доставлен | доставлен |
| `cancelled` | отменён | отменён |

## Ответ пользователю

Таблица: номер отправления, статус по-русски, дата (МСК), товары (артикул × шт), сумма по цене продавца, склад или
кластер. В первой строке — период, схема и фильтр. Все строки, без сокращений; больше ~50 отправлений — файлом:
`postings_fbo_export` / `postings_fbs_export` (xlsx или csv, те же вкладка и фильтры).
