# claude.ai, чат Claude Desktop и Cowork

Плагин, добавленный в «Настроить → Плагины» (Customize → Plugins), хранится в аккаунте: он есть в чате на сайте, в
приложении и на телефоне, в Cowork и в Claude Code (как `seller-ai@synced`).

## Как узнать

- Чат claude.ai или Claude Desktop: терминала нет — скрипт не запустить. Шаги ниже агент говорит, только если пользователь
  спросил об обновлении или видно, что навыки отстали (инструмента из навыка нет, сервер прислал `plugin_outdated`), — один
  раз за разговор: включённой синхронизации отсюда не видно, и напоминать в каждом разговоре незачем.
- Cowork и Claude Code получают плагин из аккаунта копией `~/.claude/plugins/synced/<…>/seller-ai/`; там скрипт
  запускается (`claude-code`) и отвечает `needs_user` с этими же шагами.

## Обновить сейчас

Настроить → Плагины → маркетплейс `alvenstudio/seller-ai-plugin` → «Check for updates». Новая версия приходит на аккаунт
сама, принимать ничего не нужно.

## Автообновление

У маркетплейса, добавленного с github.com, — переключатель «Sync automatically» («Синхронизировать автоматически», шаг 2
README плагина). Ключа в файлах нет: включает только пользователь, и с этой машины не видно, включён ли он. Маркетплейсы,
которые синхронизирует организация, настраивает администратор.

## Версия на диске

Только у копий Cowork и Claude Code: `~/.claude/plugins/synced/<…>/seller-ai/.claude-plugin/plugin.json`; время последней
синхронизации — `lastUpdated` (миллисекунды) в `manifest.json` той же папки `<…>`. Моложе 30 минут — скрипт отвечает
`skipped`.

## Как новая версия доходит до сессии

- Чат: новые разговоры.
- Cowork: следующая задача (компоненты плагина загружаются при её старте).
- Claude Code: синхронизация в фоне при каждом запуске; в открытой сессии — «Plugins changed. Run /reload-plugins to
  activate», `/reload-plugins` вводит пользователь.

## Сказать пользователю

«Чтобы навыки Seller AI обновлялись сами: Настроить → Плагины → маркетплейс seller-ai → включите «Sync automatically».
Обновить сейчас — «Check for updates» там же.» Плагин, загруженный архивом (Добавить → Загрузить плагин, `plugin.zip`), не
обновляется никогда: удалить его и добавить маркетплейс `alvenstudio/seller-ai-plugin`.

code.claude.com/docs/en/plugins/loading («Plugins synced from claude.ai»).
