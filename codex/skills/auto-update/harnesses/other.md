# Другие клиенты

## Клиенты MCP Skills

Клиенты расширения MCP Skills (SEP-2640, `io.modelcontextprotocol/skills`) берут навыки с MCP-сервера Seller AI
(`skills/list`, `skill://…`): локально обновлять нечего, сервер отдаёт последнюю версию, а клиент перечитывает список при
запуске или переподключении сервера. `--harness mcp-skills` → `up_to_date`. Скрипта у такого навыка на диске может и не
быть — тогда проверка не нужна.

## Архив plugin.zip

`https://seller.alven.studio/mcp/plugin.zip` — снимок без обновлений: в каком бы клиенте он ни стоял, новых версий не
будет. Поставить плагин из маркетплейса `alvenstudio/seller-ai-plugin` по README плагина, архивную копию убрать. Плагин дева
ставится только архивом: новая версия — новый архив.

## Харнесс не узнан

`unknown_harness`: в `notes` — где на этой машине есть копии плагина. Запусти с `--harness` по таблице SKILL.md. Клиента
нет в таблице — подключи MCP-сервер `https://seller.alven.studio/mcp` и навыки по README плагина («Другие агенты»).
