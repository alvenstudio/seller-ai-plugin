# Обновления плагина Seller AI

Новые версии навыков Seller AI выходят часто, а харнессы обычно забирают их только при запуске: сессия, открытая утром,
вечером работает на прежних навыках. Этот навык проверяет обновление во время работы и включает автообновление там, где
его можно включить.

## Когда

- **Первое обращение к инструментам Seller AI в разговоре** (MCP или навык `cli`) — запусти проверку сразу, можно вместе
  с первым вызовом: задачу она не задерживает.
- **Во время работы** — снова, если с прошлой проверки прошло больше 30 минут. Чаще не нужно: скрипт и сам ничего не
  запускает (`skipped`), если харнесс обновлялся меньше 30 минут назад.
- **Просьба пользователя** («обнови плагин», «проверь обновления», «включи автообновление») — с `--force`.
- **Нет терминала** (чат claude.ai, Claude Desktop) — проверить нельзя. Шаги из `harnesses/claude-app.md` сказать, только
  если пользователь спросил об обновлении или видно, что навыки отстали (инструмента, который называет навык, нет; сервер
  прислал `plugin_outdated`), — один раз за разговор.

## Вызов

```bash
python3 "<папка навыка>/scripts/check_update.py"                   # харнесс узнаётся сам
python3 "<папка навыка>/scripts/check_update.py" --harness codex   # узнал не тот или unknown_harness
```

`--force` — проверить, даже если харнесс обновлялся меньше 30 минут назад; `--dry-run` — только показать, что было бы
сделано (поле `would`), ничего не меняя. Путь — от папки этого навыка, в кавычках: в нём бывают пробелы. Своих файлов
скрипт не ведёт, в сеть ходит только командами харнесса (`claude`, `codex`, `copilot`, `hermes`) и `git`.

## Ответ

Одна строка JSON:

| Поле | Что значит |
|---|---|
| `harness` | где работает агент (таблица ниже) |
| `installed` → `now` | версия плагина на диске до проверки и после |
| `status` | `up_to_date` — новее нет; `updated` — обновлён сейчас; `skipped` — харнесс обновлялся меньше 30 минут назад; `needs_user` — нужен шаг пользователя; `unknown_harness` — харнесс не узнан; `error` — проверка или команда не прошла |
| `auto_update` | `on` — включено; `enabled_now` — включил сейчас; `unavailable` — у этой установки автообновления нет; `needs_user` — включает пользователь |
| `changed` | что скрипт изменил на этой машине: файл, ключ, было → стало; версию плагина; ссылки навыков |
| `next_step` | что сказать пользователю: шаг обновления и включения автообновления, как новая версия дойдёт до сессии |
| `notes` | подробности: отметка харнесса и её возраст, версия этой сессии, выполненные команды |

- `up_to_date`, `skipped` и пустой `changed` — пользователю ничего не говорить.
- `updated` — одна строка: «Плагин Seller AI обновлён: 1.15.2 → 1.16.0» и `next_step` — как новая версия дойдёт до сессии
  (в Claude Code `/reload-plugins` вводит пользователь: агент этого не может). Задачу продолжай: до перезагрузки
  работают прежние навыки.
- `needs_user` — передай `next_step` один раз за разговор; та же проверка позже с тем же `next_step` — без нового
  сообщения.
- `changed` не пуст — перечисли пользователю, что изменено, и включённое автообновление тоже.
- `error` — одна строка в конце ответа с сутью из `notes` и `next_step`; задачу продолжай.
- `unknown_harness` — найди харнесс по таблице и запусти с `--harness`.

Команду, которую `next_step` поручает агенту (Codex: обновление вне песочницы), выполняй только с одобрения пользователя,
как требует харнесс.

## Харнессы

| Харнесс | Как узнать | Файл |
|---|---|---|
| Claude Code: терминал, IDE, вкладка Code приложения Claude | `CLAUDECODE=1`; навык в `~/.claude/plugins/` | `harnesses/claude-code.md` |
| claude.ai, чат Claude Desktop, Cowork | нет терминала; в Claude Code — `seller-ai@synced` | `harnesses/claude-app.md` |
| Codex CLI и приложение ChatGPT (Codex) | навык в `~/.codex/plugins/`; `CODEX_SANDBOX` | `harnesses/codex.md` |
| VS Code с GitHub Copilot, Copilot CLI | `~/.vscode/agent-plugins/`, `~/.copilot/installed-plugins/` | `harnesses/vscode-copilot.md` |
| Cursor | `~/.cursor/plugins/` | `harnesses/cursor.md` |
| Hermes Agent | `~/.hermes/plugins/seller-ai` | `harnesses/hermes.md` |
| OpenCode | клон плагина, ссылки в `~/.config/opencode/skills/` | `harnesses/opencode.md` |
| Другие: клиенты MCP Skills, архив `plugin.zip` | навыки пришли с MCP-сервера или из архива | `harnesses/other.md` |

Файл харнесса нужен, когда скрипт не помог: как обновить руками, как включить автообновление, где версия на диске и когда
новая версия доходит до открытой сессии.
